# Data Science Projects – Simplilearn's Data Scientist Master’s Program

## 📖 Overview
This repository contains a collection of end-to-end data science projects completed as part of the **Data Scientist Master's Program by Simplilearn**. These projects span R programming, Python-based analysis, and machine learning applications on real-world datasets.

---

## 🗂️ Projects Included

### 1️⃣ Insurance Factor Identification (R)
- **Goal:** Identify key factors influencing motor insurance claims and premiums.
- **Techniques Used:** Data cleaning, EDA, multivariate analysis, regression modeling.
- **Outcome:** Recommendations for premium pricing and branch location strategies.

### 2️⃣ Retail Analysis with Walmart Data (Python)
- **Goal:** Forecast weekly sales across 45 Walmart stores.
- **Techniques Used:** Regression models, data visualization, time series insights.
- **Outcome:** Achieved 86% prediction accuracy and uncovered drivers like holidays and CPI.

### 3️⃣ Employee Turnover Analytics (Machine Learning – Python)
- **Goal:** Predict employee attrition and identify influencing factors.
- **Techniques Used:** Classification models (Logistic Regression, Decision Trees), feature importance, model evaluation.
- **Outcome:** Built predictive models with strong accuracy for HR retention planning.
